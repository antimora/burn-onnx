# onnx-ir-derive

Part of the [burn-onnx](https://github.com/tracel-ai/burn-onnx) project.

Derive macros for [onnx-ir](https://github.com/tracel-ai/burn-onnx/blob/main/crates/onnx-ir/README.md).

## Overview

This crate provides procedural macros used internally by `onnx-ir`, such as `NodeBuilder`, which
generates test builders for IR node structs. It is an implementation detail of `onnx-ir`; you do not
need to depend on it directly.
